# Football League Manager

## Matchday and Stats Upgrade

This build adds:
- Around the Grounds fixture/results panel
- Golden Boot and Golden Glove leaderboards
- Live yellow cards, second yellows and straight red cards
- Match injuries with recovery periods
- Suspension consequences
- Touchline shouts with morale-based positive or negative effects
- Red-card performance penalties
- Expanded match timeline and commentary events
- Service worker cache updated to v9

Replace the existing game files with the files in this package. Existing local saves remain supported.
